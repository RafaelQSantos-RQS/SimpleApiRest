# Rust + API Resources

## Knowledge

- [Book: _The Rust Programming Language_ (Brown)](https://doc.rust-lang.org/book/)
  Canonical. Use for: revisão rápida de qualquer conceito base (chapters 10-20 cobrem generics, traits, async, patterns avançados).
- [Book: _Rust Async Book_](https://rust-lang.github.io/async-book/)
  Aprofundamento em async/await, executors, Futures. Use for: quando formos além do básico de tokio.
- [Book: _Rust API Guidelines_](https://rust-lang.github.io/api-guidelines/)
  Padrões oficiais de design de API. Use for: decidir assinaturas de função, traits, nomenclatura.
- [Reference: axum docs](https://docs.rs/axum/latest/axum/)
  Docs oficiais do framework. Use for: extractors, state, middleware, routers.
- [Reference: sqlx docs](https://docs.rs/sqlx/latest/sqlx/)
  Docs oficial. Use for: queries, migrações, pool, transações.
- [Handbook: Apollo Rust Best Practices](https://github.com/apollographql/rust-best-practices)
  Já instalado como skill local (.agents/skills/rust-best-practices). Use for: idioms, clippy, error handling, performance.
- [Article: "Error Handling in Rust" — alexeden.top](https://alexeden.top/posts/rust/error-handling/)
  Boa referência sobre thiserror/anyhow e hierarquia de erros.
- [Docs: jsonwebtoken crate](https://docs.rs/jsonwebtoken/latest/jsonwebtoken/)
  Para a implementação de JWT. Use for: claims, validação, expiração.
